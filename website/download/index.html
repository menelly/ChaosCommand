Chaos Command is completely free. No price, no trial, no unlock, no in-app purchases, no ads. Get it from a store if you want automatic updates, or download it straight from this page if you’d rather not use one. Same app either way.

⚠️ Pick one channel and stay on it. Store builds and the downloads below are signed with different keys, so your device treats them as two different apps — they will not update over each other. Switching means uninstalling first, which deletes your local data. Export your data before you ever switch.

Windows

Installer · Easiest

Standard installer. Double-click, install, done. Creates a Start Menu shortcut.

Download .exe — v1.0.7 (27 MB) Or .msi — v1.0.7 (29 MB) Or .msix — v1.0.7 (29 MB)
Which one? Take the .exe — it is the ordinary double-click installer and the easiest path by a mile. The .msi is the same build for anyone who needs an MSI (managed machines, group policy). The .msix is the packaged build that also goes to the Microsoft Store, and sideloading it means trusting its certificate first — only worth the trouble if you specifically want that format. All three are v1.0.7 — same app.

Expect a SmartScreen warning: “Windows protected your PC” / “Unrecognized app.” That is normal for any app whose signature hasn’t built up reputation yet — it does not mean the file is unsafe. Click More info → Run anyway. Want to check first? Read every line on GitHub — the same source these binaries were built from.

Android

APK · Sideload

Universal APK — phones and tablets, ARM and x86. Install from your file manager, or via ADB.

Download .apk — v1.0.7 (175 MB)
Expect an “Install unknown apps” prompt: Android blocks sideloaded APKs by default. Open the downloaded file and your phone will ask you to allow your file manager or browser to install apps — toggle it on, install, then toggle it back off. Same flow AAPS, Trio and Loop use.

It is a big file because everything runs on your phone — there is no server doing the work, so the work ships with the app.
Verify what you downloaded. SHA-256 checksums for every file on this page: SHA256SUMS.txt. On Windows: certutil -hashfile <file> SHA256. On Linux/Mac: sha256sum <file>. If a hash doesn’t match, don’t run it — tell us.

Why we host these ourselves

  • Not everyone can use an app store. Store accounts, region locks, managed devices, an ancient tablet that still works fine — none of that should stand between you and a symptom tracker.
  • Stores are a convenience, not a gatekeeper. They handle updates and signing, which is genuinely useful. They are not the only door, and we are not going to pretend they are.
  • The app is free in every channel. There is no paid tier hiding behind a store listing. Nothing is withheld from the direct download.
  • Your data never leaves your device in any version. That is the point of the whole thing, and it does not change based on where you got the file.
No cloud. No telemetry. No analytics pings. No accounts. Your data stays on your device. Update checks are opt-in only — nothing phones home unless you press a button.
Source-available (PolyForm Noncommercial). Don’t take our word for any of the above — read the entire codebase on GitHub. The binaries on this page were built directly from that source. Spot something sketchy? File an issue. Want to fork it for personal or research use? Go ahead.

Small clinic, mutual aid group, researcher, solo practitioner who can handle your own setup? Reach out — we’ll probably just say yes. The reason we ask large commercial users for a license fee isn’t to gatekeep: it’s that if a big org needs us to provide ongoing support, we’d have to pay someone to do that work. The license fee funds the support. If you’re bringing your own hands, you’re not creating that burden — so you’re not creating that cost.
