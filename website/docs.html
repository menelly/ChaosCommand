Quick start

Five minutes from install to your first tracked thing. ⏱️ Initial installation and first-use configuration.

  1. Get it. Build from source for free, or grab the app-store version (Windows, Mac, and Android; a one-time $25, with scholarship keys if you're buying ramen instead of software). Details here. You can run it on desktop and phone simultaneously.
  2. Pick a theme. First launch lands you on theme selection. Lavender is the soft default. Migraine-sensitive? Pick Calm or "Tone It Down Taupe". Cyberpunk vibes? Phosphor or Segfault. You can change this any time in Settings.
  3. Set your PIN. Your PIN is your local database isolation key. Multiple users can share a device with separate PINs and separate databases. The PIN is local—there's no recovery email, because there's no server to store it. Write it down somewhere safe.
  4. Start with one tracker. Don't try to fill everything out. Pick the thing that's bothering you most this week. Sleep, pain, migraines, food, or mood. Track it for three days. Add another if you want.
The pressure-free principle: Almost every field in Chaos Command is optional. There are no required streaks, no shaming push notifications, and no "you missed 3 days" guilt-trip badges. Confetti happens when you log something—that's the entire reward loop, and you can turn it off. Skip a day, skip a week, come back when you're ready. The data you have is the data you have.

Routines (Batch logging)

Batch-log a set of trackers in one flow instead of opening each separately. 🔄 Workflow automation for multi-tracker data entry.

If you have to open and close ten different tracker cards every morning, you will stop tracking. **Routines** fix this by chaining your chosen trackers into a single, consecutive checklist flow.

How to build a Routine

  • Navigate to **Settings → Routines → New Routine**.
  • Give it a name (e.g., "Morning Check", "Post-Meal", "Crash Assessment") and select which trackers (including your custom Forge trackers) belong in the sequence.
  • Reorder them to match the flow of your day (e.g., Vitals → Med Adherence → Energy/Spoons).

Running a Routine

  • Tap **Run** on your Routine card from the home dashboard.
  • The **Next-on-Routine flow bar** will appear at the bottom of the screen, prompting you through the sequence.
  • **Copy Last:** Clone your most recent entry with one tap if nothing changed.
  • **Nothing Today:** Tap this to log a blank or "normal" day. (In this database, a normal day is real data, not an empty cell).
  • **Skip:** Skip a tracker in the sequence; you can undo the skip at any point during the run.
  • You can run the same Routine multiple times a day (each run is a distinct, timestamped session).

The trackers

50+ modules organized into five big buckets. Use what you need. Hide what you don't. 🗃️ Modular tracking categories with toggleable visibility.

Body

Pain

Location, severity, type, triggers, what helped — with a full 911 red-flag engine (MI, aortic dissection, cauda equina, AAA). Severity uses descriptive labels alongside numbers because "7/10" doesn't mean the same thing on different days.

Sleep

Duration, quality, wakeups, nap data, pre-sleep factors. Surfaces factor-to-quality correlations (caffeine, screens, relaxation).

Energy & pacing

Spoon-theory daily budget with a PEM-risk meter. Track activity exertion vs. crash-day correlation.

Vitals

Routine baseline BP, HR, SpO₂, temperature, respiratory rate, weight — with at-a-glance thresholds. Feeds the doctor PDF.

Dysautonomia

POTS/IST, BP, GI, temperature, and SpO₂ episodes. Lite-vitals capture (resting/sitting/standing HR + delta), interventions like box breathing and electrolytes.

Cardiac

Arrhythmia, chest pain, syncope, palpitations — a 15-value rhythm picker, home-ECG fields, and a 911 engine (MI/PE/VT, dissection). Cross-links to dysautonomia and labs.

Respiratory

Asthma, shortness of breath, cough, wheeze, pleuritic pain. Peak-flow zones, SpO₂ low, inhaler response, and an anaphylaxis detector (EpiPen + 911).

Pulse oximetry

Spot readings or overnight session reports from recording oximeters — O₂ score, ODI desaturation indices (3% / 4%), SpO₂ and pulse distribution bands. Feeds the doctor PDF.

Seizures

Eight types including autonomic (the kind misdiagnosed as POTS/MCAS/panic), aura→ictal→postictal phases, status-epilepticus detection, and seizure first-aid for witnesses.

Neuro

Weakness, numbness, tremor, gait/balance, fasciculations, speech/swallow — with distribution patterns (coat-hanger, stocking-glove) and MS-aware framing. Cross-lists with Joint & muscle.

Head pain

Seven episode types (migraine ± aura, cluster, tension, sinus, worst-of-life), aura mapping, delta-from-baseline, and SNOOP red flags (SAH, meningitis, stroke, GCA).

Autoimmune / connective tissue

Systemic CTD/rheum picture — sicca, Raynaud's, mechanic's hands, inflammatory rash, arthralgia, serositis. Cross-lists into Skin, Joints, and Neuro.

Thyroid

Hypo/hyper symptoms, labs (TSH/free T4/T3/TPO/TRAb), meds and dose response, with thyroid-storm / myxedema / Graves'-eye warnings.

Adrenal

Addison's/Cushing's symptoms, cortisol pattern, a sick-day / stress-dose log, and an adrenal-crisis warning engine.

Diabetes

Glucose, ketones, insulin, carbs — with time-in-range (low/normal/high), distribution, and coaching. T1/T3c-aware.

Upper digestive

Nausea, reflux/GERD, gastroparesis, indigestion. Triggers, treatments, severity, duration. Cross-links to dysautonomia, food, bathroom.

Bathroom

Bowel and urinary episodes with the full Bristol Stool Scale 1–7, blood-color mapping, and a GI 911 engine. Optional, tag-excludable from any report.

Genitourinary

Voiding, retention, incontinence, infection — a nine-scenario infection triage, fluid balance / catheter output, gender-neutral pain locations.

Skin

Rash, hives, eczema, wounds, lesions, plus an autoimmune-lesion group (malar, discoid, Gottron's). ABCDE mole module, photo timeline, and a 911 engine for anaphylaxis and SJS/TEN/DRESS.

Joint & muscle

Per-joint tracking across 30+ named joints with laterality, plus a separate muscle model (coat-hanger, proximal/distal). EDS-friendly (subluxation, self-reduction, ROM impact). Cross-lists with Neuro.

Lines & tubes

Complications of indwelling devices — PICC/port/central lines, ostomies, Foley/suprapubic, NG/G/GJ feeding tubes, trach, drains. Red-flag engine for CLABSI, air embolism, and dislodged immature-tract tubes.

Weather & environment

Barometric pressure as a first-class trigger (high/low/swings/"pressure hell") plus environmental-allergen reactions, on a 1–10 impact scale.

Reproductive

Cycle, flow, symptoms, libido, and full fertility tracking — BBT charting, OPK, cervical fluid, and a multi-factor ovulation predictor. Gender-neutral by default. Includes the G-Spot scoped delete (see Privacy). Disable the whole section if it's not relevant to you.

Postpartum & newborn

Clinician-reviewed. Recovery (lochia, fundus), feeding (latch, sides, pump/bottle), and baby (diapers, weight, jaundice) — with live red-flag banners for postpartum hemorrhage, mood crisis, and newborn fever. Gender-neutral parent/feeding language.

Mind

Anxiety

Eleven episode types including panic, social, OCD-shaped, and meltdown vs. shutdown (AuDHD-aware). Somatic and mental signs, triggers, what helped, and a full 988 crisis-marker set if you flag.

Brain fog

Cognitive function on a usable scale, not a medical-survey one. Triggers, treatments, and trend windows.

Mind & mood

Mood, cognition, energy, motivation, and regulation — including rapid-cycling and the mixed-state window. Crisis resources baked in if you flag.

Coping & regulation

A guided technique runner with a timer — box breathing, PMR, 5-4-3-2-1, DBT opposite-action and more — that you rate helpful or not, so it learns what actually works for you.

Crisis support

An editable safety plan, hope reminders, and 988/911 plus US and international resources — accessible fast when you need it.

Sensory

Overload events (triggers, symptoms, recovery, shutdown flag) and a comfort toolkit, across 12 modalities including vestibular, proprioceptive, and interoceptive. Built for autistic and post-concussion needs.

Journal

Per-day entries with brain-dump, therapy, gratitude, and creative spaces. Markdown export, inline images, search.

Choice

Substance

Deliberately non-moralizing logging — alcohol, cannabis, nicotine, recreational/off-label. Method, context, effects, intensity. Neutral tone, no lectures.

The Forge — build your own trackers

For when your weird body has a thing the 50+ default trackers don't cover. 🛠️ User-defined custom tracker creation.

The Forge is a no-code tracker builder. If you are undergoing an experimental medication trial, tracking a rare regional symptom, or need to monitor a specific behavioral reaction, you don't need a new app. You build it here.

How to build a tracker

  1. Go to **Settings → The Forge → Create Tracker**.
  2. Set the name, description, and pick a custom icon.
  3. Add your fields. You can mix and match field types:
    • **Severity Scale:** A 1–10 slider with optional custom labels (e.g., "Mild / Screaming").
    • **Checkbox:** For simple yes/no events.
    • **Number:** For values like dosage, volume, or count (specify custom units like `mg` or `oz`).
    • **Multi-select / Single-select:** Build custom dropdown option lists.
    • **Duration / Timer:** Log how long an event lasted.
    • **Photo:** Attach images directly to the entry (stored in-app, not in your camera roll).
  4. **Tag Associations:** Link your custom fields to default categories (e.g., bind a numeric custom field to the "Pain" correlation track).
v0.7.0 Update — In-Place Editing: You can now **edit existing custom trackers**! You can add new fields, rename options, or delete columns on a tracker you've been using for weeks. Chaos Command automatically migrates your database schema under the hood—**you will not lose a single previously logged entry** when you update the tracker's structure.
Desktop-Only Creation: Custom tracker *creation* and *schema editing* are desktop-only features (Windows, Mac, Linux). The structural database mapping requires heavy schema alterations that mobile storage engines cannot safely guarantee. Once built on desktop, however, your custom trackers **sync to your mobile app** and are fully loggable on your phone.

Sync across devices

Track on your phone, look at the data on your desktop. Both. Either. Whatever. 📲💻 Cross-device synchronization.

How it actually works

This is the part that matters: nothing ever touches our servers. There is no Chaos Command cloud. There is no remote database. Sync is peer-to-peer (P2P) between your own devices over your local WiFi network, encrypted end-to-end.

  1. Install on both devices (e.g., desktop and phone). Each device initializes its own local, isolated Dexie/IndexedDB database.
  2. Get both devices on the same WiFi network. P2P discovery requires same-network visibility.
  3. On the source device: Go to **Settings → Sync → Pair Device** to generate a local pairing QR code. This code contains local IP addresses and a temporary cryptographic handshake token.
  4. On the receiving device: Scan the QR code. The devices establish a direct TCP connection over your local network.
  5. Sync on demand: Database changes copy directly between the devices. Once paired, they will automatically attempt to sync when both are running the app on the same network.
The Storage Asymmetry: Desktop uses a hybrid SQLite storage router. Mobile (Android/iOS) uses a strict Dexie/IndexedDB database to respect OS storage boundaries. When you sync, the mobile app gets a optimized, lightweight history subset, while the desktop database retains your full, uncompressed multi-year document and lab library.

Document & lab parsing

Upload a doctor's note. Real NLP reads it. Not regex. Not keyword search. Actual medical NER. In your browser. 📄 In-browser biomedical NLP for clinical document extraction.

Instead of manually typing out long lab reports or specialist letters, you can drop them directly into the app. The parsing pipeline runs **entirely in-browser** using local machine learning models—your files never leave your device.

The Medical NLP Engine

  • **Local NER:** The app downloads the `d4data/biomedical-ner-all` model (ONNX int8 quantized, ~75MB) to your browser cache on first use. All named-entity recognition (NER) runs locally.
  • **Entity Extraction:** It scans medical text and extracts:
    • **Diagnoses:** Differentiates active problems from ruled-out or historical issues ("no signs of thyroiditis" is correctly negated and not flagged as a positive diagnosis).
    • **Medications:** Captures drug names, dosages, and frequencies.
    • **Lab values & ranges:** Matches test names to their numerical values and reference ranges.
  • **Impression Reader:** You can optionally activate a local LLM (`Qwen2.5-0.5B-Instruct` via Transformers.js) to summarize free-text radiology and pathology impressions into plain-language findings. (Disabled by default).

The Lab Parser & Guardrails

We support structured parsers for **Mayo Clinic, Intermountain, Halifax (with OCR), and Advent Health** portals, alongside a fallback generic parser. If a value is misread, you can edit it inline directly on the trend chart.

Upload Guardrails: 1. **Duplicate Detection:** Chaos Command hashes document contents. If you upload the same PDF twice under different names (e.g., `LabReport.pdf` and `Download(2).pdf`), it flags the duplicate before importing to prevent duplicate data points. 2. **Demographics Match:** It reads the header name/birthdate and compares it with your app profile, warning you if you are accidentally importing a child's or partner's lab results into your own trend charts.

Pattern engine & correlations

So you can stop wondering if it's the weather, the gluten, or the existential dread. 📊 Cross-tracker correlation analysis and pattern detection.

The Pattern Engine runs statistical correlation models across your historical data to surface relationships between independent variables (e.g., environmental factors, choices) and dependent symptoms.

Types of Correlations Analyzed

  • **Lagged Pain Spikes:** Finds if a drop in sleep quality correlates with a pain flare 24 or 48 hours later.
  • **Barometric Pressure Swings:** Correlates head pain and joint stiffness with barometric pressure changes (captured via local environment/weather logging).
  • **Symptom Clustering:** Identifies which symptoms move together (e.g., joint pain and brain fog flare concurrently).
  • **Work-Disability Correlation:** Tracks your average symptom severity on days you logged a "Missed Work" event versus days you worked. This produces a stark, readable bar chart that serves as clear, quantified evidence for SSDI claims and accommodation requests.
Pearson Correlation Coefficients ($r$): The engine calculates standard Pearson correlations. A positive value ($r > 0$) indicates symptoms move together; a negative value ($r < 0$) indicates an inverse relationship (e.g., more hydration correlates with fewer migraine hours).

PDF reports — three audiences

Doctor mode. Attorney mode. Personal mode. Pick the audience, get the report. 🖨️ Multi-audience PDF export with tailored content profiles.

Exporting a raw database dump is useless to a busy doctor. Chaos Command builds polished, structured PDF reports designed specifically for the person reading them.

1. Doctor Mode (The Specialist Template)

  • **ICD-10 Code Suggestions:** Automatically tags your symptoms with relevant clinical codes.
  • **Clinical Statistics:** Replaces narratives with medians, standard deviations, and time-in-range metrics.
  • **Specialty Pre-Selection:** Select your target specialist (e.g., "Rheumatology") and the app pre-selects the relevant trackers (Joints, Autoimmune, Vitals) while hiding unrelated trackers (e.g., reproductive details or anxiety spikes) so your doctor doesn't get overwhelmed.

2. Attorney Mode (The Disability Template)

  • **Functional Limitation Mapping:** Emphasizes severity trends, functional mobility impact, and lines/tubes complications.
  • **Missed-Work Logs:** Formats a clean table of missed days, matching symptoms on those specific dates to demonstrate functional incapacity.
  • **Accommodation Requests vs. Denials:** Generates an chronological timeline of requests made to employers or schools and their corresponding responses.

3. Personal Mode (The Self-Reflective Template)

  • **Plain-Language Summaries:** Written for you, not a court or clinic.
  • **Journal Inclusion:** Optional rendering of your text entries alongside your numerical symptom trend lines.
Tag Exclusions: You can tag any individual log entry (e.g., `#private` or `#gastric`). When generating a report, you can set the exporter to exclude any tag. This gives you absolute control over what details make it onto the printed page.

Privacy & the G-Spot

Your data lives on your device. Period. We literally cannot see it. And you've got honest emergency tools when you need them. 🔒 Local-first data architecture and honest emergency data controls.

Because this app is local-first, **we do not have a server database.** We do not run trackers, analytics, or user registration. We cannot sell your data, and we cannot hand it over to a third party or government agency because **we do not possess it.**

Emergency Data Controls

Chronically ill, trans, and pregnant individuals often face unsafe environments (domestic, state, or employment). Chaos Command provides transparent, non-deceptive data safety features:

  • **Emergency Logout:** A prominent "Logout" button at the bottom of the sidebar instantly closes your active database and returns to the PIN screen. Non-destructive; the database remains encrypted on-device.
  • **The G-Spot (Scoped Reproductive Delete):** A deliberate, confirmed, double-gated **irreversible deletion** of only your reproductive, menstrual, and cycle data. If carrying this information becomes a legal or physical risk in your region, this button wipes that specific table from your local IndexedDB database in seconds while keeping your pain, sleep, and vitals history completely intact.
  • **Plausible Deniability:** The built-in public demo uses PIN `1111`. If forced to open the app, entering `1111` opens a realistic, pre-populated profile with fake data, concealing your actual private PIN profile.

Encrypted Backups

You can export your database as a password-encrypted JSON file (using **AES-256-GCM** derived via PBKDF2). This file can be stored on your local drive or homelab. Without your backup password, the file is functionally raw entropy.

For caregivers & partners

If you're tracking for someone, or sharing data with someone you trust. 🤝 Caregiver and partner sharing configuration.

Chaos Command supports caregivers without building invasive cloud portals.

  • **Multi-Profile Tracking:** Set up separate PINs for each person you care for (e.g. `2222` for child A, `3333` for child B). Each PIN operates a completely independent database.
  • **Tag-Filtered Sharing:** Generate doctor or attorney PDFs and use tag exclusions to strip out personal notes, diary entries, or specific trackers before exporting.
  • **The Privacy Bound:** We do not build remote surveillance channels. We believe caregiving requires consent. Do not use this tool to track someone without their active cooperation.

Self-hosting & advanced setups

For the homelab folks who want their data parked on hardware they own. 🏠 Self-hosted deployment patterns.

Out of the box, the app is local-first. There is no server. However, if you are a developer or homelab enthusiast, you can run Chaos Command as a self-hosted web app.

Technical Architecture

  • **Storage Router:** Desktop builds route data through a hybrid SQLite controller. Web and mobile builds compile to Dexie.js (IndexedDB).
  • **NLP Offline:** The document NER model downloads directly from Hugging Face to browser cache on first run and executes via ONNX Runtime Web. No backend python server is required.
  • **License Loop:** Unlocking the store build uses Ed25519 signatures. The check runs entirely offline on-device; the app never phones home to verify keys.

To deploy on your own server, clone the repository and run the Next.js project. You can access the open code at github.com/menelly/ChaosCommand.

Troubleshooting

Sync is failing

  • Ensure both devices are connected to the same local WiFi router.
  • Verify your router doesn't have "Client Isolation" or "Guest Mode" enabled, which blocks P2P traffic.
  • Make sure the app is open on both screens during the sync flow.

Lab Parser errors

If the ONNX model fails to load or text reads incorrectly, check the console logs. Image-based PDFs require OCR to be toggled on in Settings. You can correct any OCR typos directly on the lab results table.

Lost my PIN

There is no recovery. Your PIN is the cryptographic key for your local database. If you lose it and haven't exported an unencrypted backup, the data is permanently lost. This is a design constraint for security.
